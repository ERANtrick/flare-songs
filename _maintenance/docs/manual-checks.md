# 手動確認と未対応範囲

自動テストはDOM・入力・通信・描画・focus・computed styleを確認します。実際の支援技術による読み上げ品質や、端末固有のフォント／native selectの見た目を完全には保証しません。

UIを変更するPRでは、少なくとも375／768／1280px・日英・ライト／ダークで、文字切れ・重なり・横スクロール・操作対象を確認してください。F02の自動検査は320～1280pxの9幅を含みます。

- Tab／Shift+Tab／Enter／Space：テーマ、フィルタ、星、アコーディオン、追加表示。
- お気に入りだけ表示中の解除：次／前／最後1件のfocus。マウスやstorage同期時にfocusを奪わないこと。
- NVDA＋Chrome等：検索入力の通知が1文字ごとに過剰にならず、手動追加が通知され、自動追加が繰返し読み上げられないこと。loading／errorと0件を混同しないこと。
- タッチ端末：フィルタと右上のテーマ／言語、長い配信タイトル、ページ拡大時の操作。

F09（画像欠落時の星）は対象外です。F10ではCDN依存を同一originの固定vendorへ変更し、fallbackや新しい障害復旧機構は追加しません。関連する既存エラー試験は保持しますが、未対応の期待動作をskip成功扱いにしません。

追加候補：19/20/21/39/40/41件境界、BOM／CRLF、HTTP200でHTMLが返る場合、大きなフィールド、データ版の更新、最小限のFirefox／WebKit、タイムゾーン、色合成helperの独立例。導入時は目的・入力・期待値を小さく明示してください。
